# Aswin C — Portfolio

A static portfolio website built with HTML, CSS, and JavaScript.

## Publish with GitHub Pages

1. Create a GitHub repository. For the default GitHub Pages address
   `https://YOUR-USERNAME.github.io`, name it `YOUR-USERNAME.github.io`.
   Otherwise, any repository name works and the address will be
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME`.
2. Upload `index.html`, `Aswin_C_Resume.pdf`, this `README.md`, and the
   `.github/workflows/pages.yml` file, preserving the `.github/workflows`
   folders.
3. Ensure the repository's default branch is `main`.
4. In the repository, open **Settings → Pages** and set the build and
   deployment source to **GitHub Actions**.
5. Open **Actions** and wait for **Deploy portfolio to GitHub Pages** to
   complete. The published URL will appear in the workflow run and in
   **Settings → Pages**.

The resume is included in the published site and is publicly downloadable when
the site is public.
